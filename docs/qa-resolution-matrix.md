# 해상도별 UI 회귀 QA 매트릭스

운영 배포 전 DevTools 또는 실기기로 아래 항목을 점검하고 Pass/Fail을 기록합니다.

## 점검 환경

| 해상도 | 대상 | 합격 기준 |
|--------|------|-----------|
| 1920×1080 | 관제실 | 종합상황판 핵심 정보 스크롤 1회 이내 |
| 1600×900 | 일반 PC | 가로 스크롤 없음, KPI·차트 가독성 유지 |
| 1280×720 | 부서장 PC | 사이드바 접기 동작, KPI 3~4열, 테이블 overflow-x |
| 다크/라이트 | 전체 | 차트·배지·입력 필드 대비 유지 |

## 점검 순서 (우선순위)

1. `/` 종합상황판
2. `/volume`, `/safety`
3. `/reports`, `/settings`
4. `/staffing`, `/transport`, `/equipment`, `/briefing`

## Known limitations

- 모바일(768px 이하) 미지원
- 축약형 PDF는 운송·안전·인력 일부 항목 누락 가능
- 관리자 인증은 sessionStorage 기반 (브라우저 탭 종료 시 유지, 세션 종료 시 재로그인)
