# 중부권IMC 통합관제 대시보드 — 운영자 가이드

## 1. 접속

- **대시보드 (운영)**: https://frontend-flame-tau-97.vercel.app
- **대시보드 (개발)**: `http://127.0.0.1:5173`
- **API (운영)**: https://imc-dashboard-api-production-2929.up.railway.app
- **API (개발)**: `http://127.0.0.1:8000`
- 권장 해상도: 1280×720 이상 (관제실 1920×1080)

## 2. 일일 사용 흐름

1. **신규 PDF**를 `data/inbox/`에 넣고 아래 명령 실행 (로컬 DB + 프로덕션 반영)

```powershell
.\scripts\daily-pdf-sync.ps1 -UploadProduction
```

2. 사이드바에서 **조회 일자** 선택 (캘린더)
3. **비교 기준** 선택 (전일 / 7일 평균 / 30일 평균 / 동일 요일)
4. **종합상황판**에서 10초 내 상황 판단
5. 필요 시 분석 메뉴로 drill-down

| 시스템 관리 🔒 | 임계값·운영 일정 (관리자) |

## 4. 관리자 모드

1. **보고서·다운로드** 또는 **시스템 관리** 메뉴 클릭
2. 비밀번호 입력 (환경변수 `IMC_ADMIN_PASSWORD`, 기본값 `imc-admin`)
3. 로그인 후 🔒 → **관리자** 표시
4. 종료: 사이드바 **시스템 관리** 아래 **관리자 모드 종료**

### 관리자 작업

- **PDF 업로드**: 보고서·다운로드 → 파일 선택 → 업로드
- **보고서 삭제**: 목록에서 삭제 (confirm 후 진행)
- **임계값 변경**: 시스템 관리 → 저장
- **운영 특이 일정**: 보고서 페이지 하단 → 추가/수정/삭제

로컬에서 설정한 특이 일정·임계값을 프로덕션에 반영할 때:

```powershell
$pw = (railway variables --json | ConvertFrom-Json).IMC_ADMIN_PASSWORD
python backend/scripts/sync_production_config.py --password $pw
```

### 자동화

| 방식 | 명령 |
|------|------|
| **매일 07:00 (Windows)** | `.\scripts\setup-daily-task.ps1` |
| **inbox 감시 (60초)** | `python backend/scripts/watch_pdf_inbox.py --upload-production --password $pw` |
| **공유폴더 → inbox** | `.\scripts\sync-inbox-from-share.ps1 -SourcePath "\\server\share\imc" -UploadProduction` |

> 배포 전 반드시 `.env`에서 `IMC_ADMIN_PASSWORD`를 기본값에서 변경하세요.

## 6. 사이드바

- **« / »** 버튼: 사이드바 접기/펼치기 (1280px 환경 권장)
- 조회 일자·비교 기준은 모든 분석 화면에 공통 적용

## 7. 문제 해결

| 증상 | 조치 |
|------|------|
| 데이터 없음 | 해당 날짜 PDF 업로드 여부 확인 |
| API 연결 실패 | 백엔드(8000) 실행 확인 |
| 업로드 401 | 관리자 재로그인 |
| DB locked | 백엔드 재시작 후 재시도 |
